CITECHOICE: A Causal Audit of How Document Presentation Redistributes Citation Credit in Agentic Search

When several sources support the same fact, which ones get cited? CITECHOICE replays agentic search transcripts while varying document order and presentation. Across 113 pairs grouped into 89 families, structured rendering adds 0.50 target citations per answer; whether a source gets cited at all remains inconclusive. Human review validates 103 pairs. Controlled reordering has smaller effects than observational rank differences suggest. Repeated decoding of 30 frozen families changes 15% of binary citation decisions, showing why citation evaluation must account for generation noise.

Similar Accuracy, Unequal Evidence: Search APIs as Decision Surfaces for Tool-Using Agents

Accepted · GroundLM Workshop · EMNLP 2026

Search APIs shape the evidence an agent sees before it decides to answer, search again, or fetch a page. With one fixed agent on 100 SealQA-Hard questions, Brave, Tavily and Firecrawl achieve similar observed accuracy, but expose different supporting evidence and are associated with different retrieval paths. Similar accuracy does not establish equivalence. An oracle union covers 44 questions versus 26 for the best single provider, motivating evaluation of search APIs together with agent policy and retrieval budget.

Eval-Pair Matrix: Answer-Paired Meta-Evaluation of LLM Judges for Grounded RAG

Accepted · GroundLM Workshop · EMNLP 2026

It is now common practice to use a model as a judge for retrieval-augmented generation, sometimes a model from the same family that wrote the answer. That arrangement makes self-leniency nearly impossible to see. Eval-Pair Matrix is a controlled meta-evaluation protocol for source-grounded RAG that pairs every answer across judges, so the bias a family shows toward its own output becomes a number you can read off the diagonal.

ProfileFoundry: A Synthetic Person-Object Substrate for Privacy, Memory and Tool-Use Evaluation in LLM Agents

Accepted as poster · HAIPS Workshop · COLM 2026

Seeing how PANORAMA was used in the real world, we realized that profile generation itself was valuable to other researchers. We extended that framework into ProfileFoundry: internally consistent synthetic people and the accounts, documents, and transactions associated with them. This shared substrate lets researchers probe the same agent for what it leaks, what it retains, and which tools it uses.

PANORAMA: A Synthetic PII-Laced Dataset for Studying Sensitive Data Memorisation in LLMs

You cannot study what a model memorises about real people without endangering real people. PANORAMA is the way around that: a corpus built from internally consistent synthetic profiles, rendered into the formats personal information actually arrives in online: posts, reviews, wiki entries, listings. Fine-tuning Mistral-7B at rising replication rates shows memorisation climbing with repetition, and climbing at different speeds depending on the kind of page the information lived on.
