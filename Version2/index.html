Equal Accuracy, Unequal Evidence: Search APIs as Decision Surfaces for Tool-Using Agents

A search API is usually judged on one number: did the agent eventually get the answer right. That hides the part that actually costs something. Before any page is opened, the agent sees only ranked snippets, URLs and metadata and that surface alone decides whether it answers now, searches again, or spends thousands of tokens fetching. We argue the API is better understood as a decision surface, and measure it there: two providers can post identical accuracy while handing the agent very different evidence.

Eval-Pair Matrix: Answer-Paired Meta-Evaluation of LLM Judges for Grounded RAG

It is now common practice to use model as a judge for retrieval-augmented generation, sometimes a model from the same family that wrote the answer. That arrangement makes self-leniency nearly impossible to see. Eval-Pair Matrix is a controlled meta-evaluation protocol for source-grounded RAG that pairs every answer across judges, so the bias a family shows toward its own output becomes a number you can read off the diagonal.

ProfileFoundry: A Synthetic Person-Object Substrate for Privacy, Memory and Tool-Use Evaluation in LLM Agents

After carefully reviewing the usage of our work with PANORAMA in real world, we realized that the profile generation work by itslef has been valuable to so many. We enhanced our profile generation framework and produced ProfileFoundry, a shared substrate that is, internally consistent synthetic people, and the objects that accumulate around a person, accounts, documents, transactions so the same agent can be probed for what it leaks, what it retains and what it reaches for.

PANORAMA: A Synthetic PII-Laced Dataset for Studying Sensitive Data Memorisation in LLMs

You cannot study what a model memorises about real people without endangering real people. PANORAMA is the way around that: a corpus built from internally consistent synthetic profiles, rendered into the formats personal information actually arrives in online — posts, reviews, wiki entries, listings. Fine-tuning Mistral-7B at rising replication rates shows memorisation climbing with repetition, and climbing at different speeds depending on the kind of page the information lived on.

384,789 samples / 9,674 profiles / 1× → 25× replication
